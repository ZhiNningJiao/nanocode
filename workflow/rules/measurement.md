# 实验计时与测量口径

来源：owner 2026-09-18 决策。写进 REPORT/对比结论前自检。

- **算法性能计时**：用同资源容器内的算法内部计时（算法段的耗时），不是 HTTP 端到端。
- **HTTP 计时**：只用于「端到端体验」口径，两口径不得混报。
- **原始输入与测量定义必须写明**：输入是什么资产、单位、分辨率/规模；指标定义
  （什么算一次、什么被排除）。没有定义的对比数字不进报告。
- **案例命名去内部细节**：对外/对 owner 报告用简洁通用实例名
  （如「标准人形行走 case」），不暴露内部 tag/路径/客户细节；内部溯源用文件引用。
