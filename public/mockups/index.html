NanoCode UI — 5 Interaction Paradigms

Static prototypes. Each differs at the interaction-logic level, not just visual skin. All five are responsive (phone 390×844 + desktop). See NANOCODE_UI.md.

V1
Focus Mode
Single conversation owns the screen; chrome summoned via ⌘K overlay / tappable pill.
mobile+desktop · single-task
V2
Multi-Lane Dashboard
Parallel agent terminals in a mosaic; stacked cards on phone, expand to full-screen.
mobile+desktop · multi-agent
V3
Chat-First / Canvas
Message-centric transcript + artifact canvas (bottom sheet on phone).
mobile+desktop · review
V4
Workspace IDE
File-tree + terminal + diff triad; tree as drawer + bottom sheet on phone.
mobile+desktop · review gates
V5
Command Console
Keyboard-driven command bar (Vim/Raycast-like); ✉ toggle + touch suggestions on phone.
mobile+desktop · power-user
