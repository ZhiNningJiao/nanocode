# req16: 会话组收藏夹 UI 化 + 常驻秘书会话 + 生活小助手（主人需求 2026-07-18）

## 背景
nanocode 在单目录（同一 cwd 的项目）下已有"会话组"概念，但 UI 上没有体现。
主人在一个项目里开多个常驻 tab（三个秘书），resume/重新打开时找不到它们，要翻列表。

## 需求（主人原话要点）
1. **收藏夹**：项目内可收藏会话/tab。重新打开（resume 场景）时收藏的会话**优先显示**（置顶区），一眼看到。
2. **首批三个收藏**（9475 主项目下的三常驻秘书 tab）：
   - 秘书T1 / 秘书T2 / Codex秘书
3. **对这三个收藏会话的硬性约束**：
   - 必须 **block 显示**（结构化 block 渲染，不是 terminal/pty 那种显示）
   - 模型必须是 **Fable 5（claude-fable-5）或 GPT 5.6**（秘书必须用好模型）——收藏项要能看到并锁定模型配置，resume 后不掉回默认模型
4. **生活小助手**：在主人主项目文件夹（智凝胶/zhiningjiao 主目录项目）下加一个常驻会话：
   - label「生活小助手」，模型 **Sonnet 4.6（claude-sonnet-4-6）**，block 显示
   - 用途：主人问简单问题/找东西。无特殊人设 prompt，普通会话即可。也进收藏夹。

## UI 要求
- 收藏/取消收藏操作就在会话列表/tab 列表上，入口显眼。
- **手机端硬要求**（主人常用手机）：390×844 视口下收藏区可用，触控目标 ≥44px，验收必须含手机视口截图。

## 验收标准
- Playwright 真点击闭环：收藏一个会话 → 关掉重开项目 → 收藏区置顶可见 → 点开 resume 成功 → block 渲染 → 模型显示正确。
- 三个秘书 tab 的收藏 + 模型/显示配置落地；生活小助手会话创建成功且能对话。
- 桌面 + 手机（390×844）截图各一套。
- 推 fork-main 后在 9476 部署，主人实测。
